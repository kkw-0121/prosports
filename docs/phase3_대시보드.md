# Phase 3 — 대시보드 1차 (2026-11-27)

## 내 PC에서 보는 방법
- 폴더의 `대시보드_열기.bat`을 더블클릭 → 브라우저에서 http://localhost:8765 이 열림 (검은 창을 닫으면 꺼짐)
- 최신 숫자로 보려면 먼저 수집: `python -m scrapers.run_all` (약 1분 30초) → 다시 `대시보드_열기.bat`

## 구현한 1차 항목
| 항목 | 내용 |
|---|---|
| 헤더 | 제목, 기준일, 리그별 수집 상태(정상/지연/실패, 마우스를 올리면 사유), 엑셀 다운로드 |
| 요약 카드 | 선택한 시즌의 전체 총 관중·평균·경기 수, 종목별 카드 5개(평균 관중 전 시즌 대비 %) |
| 연도별 그래프 | 종목별 쌓은 막대 + 전체 평균 선. 선택 시즌만 진하게, 진행 중 시즌은 점선 |
| 종목별 상세 | 세부 항목별 관중·경기·평균 표, 연도별 그래프, 연맹 공식 집계 대조(일치/차이/미제공), 반영 대기 등 메모 |
| 종합 표 | 엑셀 '종합' 시트와 같은 집계, 최근 시즌이 위 |
| 엑셀 다운로드 | 양식에 숫자만 채운 파일 `프로스포츠 관중 수(YY.MM.DD 기준).xlsx` + '공식 집계 대조' 시트 |

## 엑셀 다운로드 방식 변경 (PROMPT의 ExcelJS → JSZip)
양식의 모든 시트에 **텍스트 상자(집계 기준·취합 방법·접속 경로·담당자 안내)**가 있는데,
ExcelJS는 파일을 읽었다 다시 쓰면 도형·텍스트 상자를 지원하지 않아 사라진다.
그래서 xlsx(zip) 안의 XML에서 **숫자 칸의 값만 직접 바꾸는 방식(JSZip)**으로 구현했다. 나머지 부품은 원본 그대로 복사된다.

## 원본 양식 ↔ 다운로드 파일 대조
자동 대조 결과: `docs/phase3_엑셀대조.md` (`python scripts/compare_excel.py 원본 다운로드 보고서` 로 다시 실행 가능)
- 원본 부품 39개 모두 유지, 텍스트 상자·그림·테마·인쇄설정·계산체인 **바이트 동일**
- 기존 6개 시트 745칸: 서식 다른 칸 0, 수식 다른 칸 0, 병합·열 너비·행 높이 동일
- 값이 바뀐 칸: 기준일(R4)과 자동 수집 시즌 입력 칸만 (오늘은 KOVO 2026-27 남·여 4칸, 나머지는 양식 값과 같음)
- 종합 수식은 그대로 두고 저장 결과값만 갱신 + 엑셀이 열 때 전체 재계산(fullCalcOnLoad)
- **실제 엑셀(16.0)로 열어 확인**: 오류 없이 열림, 재계산 결과 2027 행 전체 374,525명·평균 2,619명(대시보드와 동일), 시트별 텍스트 상자 수 원본과 동일
- 엑셀 화면 이미지 비교: 바뀐 곳은 기준일·2027 배구 값·전체 값뿐. 그 밖에 '#DIV/0!' 칸 모서리의 초록 오류 표시 삼각형이 원본 캡처에만 보였는데, 이는 엑셀 화면 표시이며 파일 서식(XML)은 동일

## 다운로드용 양식의 개인정보 제거 (결정: 지움)
- 원본 엑셀은 그대로 두고, 사이트용 복사본(`site/template/양식.xlsx`)만 `python scripts/make_public_template.py`로 만든다
- 지운 것: 5개 리그 시트 텍스트 상자의 'ㅇ 담당자 : 이름·직급·전화번호·이메일' 줄 5개, 엑셀 내부의 원본 파일 경로(OneDrive 폴더)
- 텍스트 상자의 나머지 안내(집계 기준·접속 경로·함수 설명)는 그대로. 스크립트가 끝에 전화번호·이메일이 남았는지 검사하고 남아 있으면 저장하지 않음
- 원본 양식을 새로 고치면(예: 새 시즌 행 추가) 이 스크립트를 다시 실행하면 됨
- 대조 기준을 이 사이트용 양식으로 바꿔 다시 확인: 서식 차이 없음, 실제 엑셀에서 정상 열림·텍스트 상자 수 동일·담당자 줄 없음
