# Phase 0 — 출처 조사 보고 (2026-11-27)

## 전제
- 5개 공식 출처 모두 robots.txt 또는 약관에 "사전 허가 없는 자동 수집 금지" 문구가 있음.
- 사용자(한국프로스포츠협회)가 **연맹 허가를 받았다고 확인**(2026-11-27)해서 조사를 이어감.
- 접근 원칙: 하루 2회, 요청 간 1초 이상, 일반 브라우저 User-Agent, 공개 화면 기준.
- **KBL 데이터 업체(sports2i) API를 직접 부르는 방식은 이 작업 환경의 권한 검사에서 막혔다.** 그래서 KBL은 공개 화면을 실제 브라우저(Playwright)로 열어 표를 읽는 방식으로 설계함.

## WKBL 대안 (경기별 관중 미제공)
- **방법 A (권장): 매일 구단별 누적치 스냅샷 → 차이로 경기별 관중 복원.** 하루 2회 `crowd.asp`를 저장하고, 어떤 구단의 홈 합계가 늘면 그날 그 구단의 홈 경기 관중으로 기록. 한 구단이 하루에 홈 경기 2번을 하지 않으므로 정확함. 단 **이미 지난 경기(현재까지 20경기)는 경기별로 나눌 수 없음**. 이 부분은 합계(27,985/20경기)로 시작점을 잡음.
- 정규/PO 구분: 정규시즌 마지막 날 스냅샷을 정규 합계로 고정하고, 이후 증가분을 PO로 집계.
- 방법 B: 협회가 WKBL에서 경기별 관중 파일을 직접 받는 방식(가장 정확).

## 남은 확인 (Phase 2에서)
- KBO `/ws` 호출을 requests로 할지 Playwright로 할지 확정
- KOVO 포스트시즌·올스타 leagueCode 확인(시즌 일정 화면의 리그 선택)
- KBL·KOVO 진행 중 시즌 경기별 합계를 엑셀 11.24 기준값과 대조
